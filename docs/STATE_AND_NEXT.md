# State of the project, and the directions open — 2026-09-09

Supersedes the 2026-09-04 version. For any next session: read this, the
current phase spec, and the review file's last addenda.

## Where the project stands, whole-arc

Six weeks from the first audit, the tool now: prices household taxation
exactly (DGFiP-validated; niches, prestations, allègements as knobs), firms
(IS/CVAE/C3S/CEBGE on real DGFiP-Ésane cells, all lines in tolerance),
wealth (IFI exact, ISF revival, backtested out-of-sample against IPP's 2017
tables), behavioural bands on adversarially-verified evidence, a macro fan
that refuses to be a number, a reform composer with a budget-neutral solver,
the fiche de chiffrage generator, a pre-registration harness whose
integrity lives in git history, the PLF coverage triage (29 fiscal articles
classified, four buckets, two headline denominators), and — in flight —
trajectories: populations uprated (never re-synthesised), every knob priced
per year with a measured legislated/reconducted basis. ~1,100 tests, CI
green on an instrument that can fail, a doctrine list, and 100+ decision
entries recording every error either way.

## In flight

When the text publishes: manifest, re-derive the triage, wire the
